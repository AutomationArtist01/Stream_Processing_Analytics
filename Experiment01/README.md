# Experiment 1: Batch Processing Case Study – Student Marks Analysis

## Overview

This experiment demonstrates batch processing using Python and the Pandas library. The program reads student marks from a CSV file, processes all records in a single batch, assigns grades, determines pass/fail status, calculates summary statistics, and saves the processed data.

## Project Structure

```text

│── Experiment_01.ipynb
│── Experiment_01_Report.pdf
│── students_marks.csv
└── README.md
```

## Technologies Used

- Python 3.x
- Pandas
- Jupyter Notebook

## Features

- Reads student data from a CSV file
- Assigns grades automatically
- Determines pass/fail status
- Calculates average, highest, and lowest marks
- Exports the processed dataset

## How to Run

1. Install Python 3.x.
2. Install the required library.

```bash
pip install pandas
```

3. Open `Experiment_01.ipynb` in Jupyter Notebook.
4. Run all cells in order.

## Expected Output

The notebook displays:

- Processed student records
- Grade for each student
- Pass/Fail status
- Average marks
- Highest marks
- Lowest marks
