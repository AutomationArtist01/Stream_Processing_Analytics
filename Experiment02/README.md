# Experiment 2: Random Stream Data Processing Pipeline

## Overview

This experiment demonstrates how random streaming data can be generated and visualized using Python and Matplotlib.

## Project Structure

```text
Experiment_02/
│── Experiment_02.ipynb
│── Experiment_02_Report.pdf
└── README.md
```

## Technologies Used

- Python 3.x
- Matplotlib
- Jupyter Notebook

## Features

- Generates random stream data
- Displays a line plot
- Displays a scatter plot
- Demonstrates basic stream data visualization

## How to Run

1. Install matplotlib.

```bash
pip install matplotlib
```

2. Open `Experiment_02.ipynb`.
3. Run all cells.
